# Контекст · Альфа-Бизнес

Хакатонная версия персонализированной новостной аналитики для руководителей крупного бизнеса: **событие → банковский тезис → признак компании → возможное последствие → что проверить**.

Ветка `hackathon/alfa-2026` отделена от `main@1f2e1ae`. Приложение — на **http://localhost:3010**, исходный личный продукт на 3000 не изменяется. Банковская оболочка и авторизация — моделируемые интеграции; операции не выполняются.

**Статус: подключение живых Gemma/GLM и реальных новостей.** По запросу пользователя добавлен режим `HACKATHON_BILLING_MODE=gateway`: тарифы не требуются, общий лимит проверяется по счётчику организаторов перед вызовом. Стоимость ответа в ₽ остаётся неизвестной. Только разрешённые модели, без Gemini fallback. Результаты и границы приёмки — [подключение шлюза](docs/hackathon-gateway.md). На live-наборе P@5=0,70 при цели 0,80: финальный тег требует улучшения ранжирования и смысловой экспертной проверки.

## Запуск

Требуются Docker Engine/Compose, Node.js 22.19+ и pnpm 11.25.0:

```sh
pnpm install --frozen-lockfile
pnpm hackathon:up
```

Команда создаёт отдельное окружение, сверяет 12 источников manifest, поднимает БД/Redis/API/worker/web/Nginx, выполняет COPY/OCR и seed. Оригиналы помещаются в `.hackathon/raw` вне Git. Если Google Drive недоступен, скопируйте файлы из предоставленной папки кейса туда и повторите команду. Ни одно платное исследование при старте не запускается. OCR и первая сборка занимают несколько минут.

Вход — «Открыть демонстрацию» или `founder@example.test` / `Alfa-hackathon-2026!`. Другие роли/ограниченный аккаунт — в [сценарии жюри](docs/hackathon-judge.md). Почта Mailpit — http://localhost:8030. Все порты привязаны к loopback. Данные сохраняются в собственных named volumes.

## Что реализовано

- Полный потоковый импорт 85 525 строк компаний, 12 514 связей с обезличенными лицами и 1 380 585 платёжных строк; COPY/staging, SHA, идемпотентность, конфликтующие варианты, Decimal/BigInt, неизвестные контрагенты и отчёт качества.
- Девять банковских PDF и 64 OCR-страницы: оригиналы, проверенные даты, текст, координаты, confidence, локальный FTS/trigram. Исторический обзор 2021 года и неизвестный день публикации золота показаны явно. Commodities performance не найден и не выдуман.
- Компания/разрешённая группа, семь профессиональных ракурсов, интересы, отрасль, риск и период. Роль меняет ранжирование, права выдаются отдельно через company grants. Ручные уточнения версионны и не затирают CSV.
- Собственный LangGraph с планом, безопасными инструментами, новостями/банковским RAG, классификацией, интерпретацией, самопроверкой, ограниченным уточнением, outbox/checkpoints и идемпотентной публикацией. Новую новость можно добавить по URL/тексту.
- Отдельные DTO для события, клиента, банка и AI. Банковская цитата проверяется по странице. Шесть блоков объяснения, источник рядом с чтением, приватный чат, обратная связь и экспертный разбор.
- Только шесть разрешённых семейств моделей, Gemma для извлечения, GLM для интерпретации/чата. Общий атомарный бюджет до 500 ₽/сутки на ключ, резервы, usage, неизвестные исходы и ограниченные повторы.
- Чёрно-красная журнальная оболочка, локальный Golos Text, прямые URL, Back/Forward, SSE/fallback, клавиатура, адаптивность и reduced motion.

Детерминированный demo использует тот же граф. Три корпоративных профиля >15 млрд ₽ и дополненные события явно синтетические; это не сведения о реальных клиентах. Единицы исходных денежных полей, валюты/периоды платежей, ставки кредитов и реальная доля рынка не выдумываются.

## Проверки

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm test:integration
pnpm hackathon:evaluate
pnpm build
```

Браузерная приёмка отдельной версии:

```sh
# Windows: переменные окружения задаются через $env:...
E2E_BASE_URL=http://localhost:3010 PLAYWRIGHT_CHANNEL=msedge pnpm exec playwright test tests/e2e/bank.spec.ts
```

Integration создаёт изолированную PostgreSQL БД и запускает worker, включая прежние применимые защитные сценарии. Настройки проверки не используют ключ организаторов. Отчёт 60 сочетаний (40 development / 20 held-out): [фактические результаты](docs/hackathon-evaluation.json). Авторская разметка и demo-метрики не являются независимой экспертизой или доказательством качества живой LLM.
