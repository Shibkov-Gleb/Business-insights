# Аудит предоставленного набора

Полный транзакционный импорт выполнен в отдельном `context-alfa-hackathon`, PostgreSQL COPY через staging. SHA-256 файлов зафиксированы в `data/hackathon/sources.manifest.json`; оригиналы находятся в игнорируемом `.hackathon/raw`.

| Источник                |   Записей | Результат                                                                                        |
| ----------------------- | --------: | ------------------------------------------------------------------------------------------------ |
| Компании                |    85 525 | 85 514 ID; один ID имеет 12 вариантов, 12 конфликтующих полей исключены из автоматических фактов |
| Физические лица и связи |    12 514 | Обезличенные связи; не доказательство собственности и не источник прав                           |
| Платёжные связи         | 1 380 585 | Decimal(38,6), count BigInt; 27 406 self-links исключаются из концентрации                       |

Сумма PAY_AMT: `55991235586000.000000` в неизвестных исходных денежных единицах. Сумма PAY_CNT: `24515786`. Создано 114 552 узла неизвестных контрагентов. Отсутствуют 85 357 значений работников СПАРК, 77 179 стран ВЭД и 4 157 стадий. Повторный импорт тех же SHA возвращает прежний import ID, не создавая записей. Другой набор требует явной миграции версии, чтобы версии не смешивались.

Единицы выручки/платежей и период платежей не подтверждены. Выручка в CSV не называется рублёвой без настройки импорта; позиция и доля показываются внутри предоставленного набора, реальная доля рынка неизвестна. Групповой ID не является правом доступа, сумма выручек не консолидированная выручка. NEGATIVEMARK не используется как кредитный риск.

Собственные три демонстрационных профиля имеют явно синтетическую выручку 42 / 28,5 / 19,2 млрд ₽. Их платёжные связи и новости отделены от оригиналов по происхождению. Новые тестовые данные не выдаются за сведения банка.

Проверки: `tests/integration/corporate.test.ts` — Decimal выше Number.MAX_SAFE_INTEGER, точный BigInt, конфликт, пропуски, unknown-контрагент, повтор COPY, отсутствие неявного доступа; полный импорт сверяется с агрегатами выше.
