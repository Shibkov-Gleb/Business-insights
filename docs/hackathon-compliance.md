## Внешние условия финальной приёмки

Нужны endpoint, API IDs разрешённых моделей, общий ключ и тарифы/правила суточного сброса организаторов. До получения данных нельзя утверждать полное соответствие, создавать финальный тег `alfa-hackathon-v1` или выдавать fixture-прогон за результат живой модели.
