# Сценарий проверки жюри

[← README](../README.md) · [Матрица 12 критериев](hackathon-compliance.md) · [Доказательства](hackathon-acceptance.md)

Основной проход занимает около 10–15 минут **после сборки и импорта**. Это работающий прототип, не кликабельный набор картинок. Идентификатор сдаваемой версии фиксируется по [инструкции](hackathon-release.md).

## 1. Запуск и вход

Из отдельного хакатонного checkout: `pnpm install --frozen-lockfile`, затем `pnpm hackathon:up`. Дождитесь migrate/import, откройте `http://localhost:3010`. На свежем окружении это demo: бесплатный проход без ключей. Если `.env` уже настроен на live, он не заменяется — используйте обычный вход и учитывайте платные вызовы.

## 3. Контрфактические проверки

- Одна макроновость при отметке кредитного продукта и без неё: различаются основания и возможный прямой эффект; ноль в наборе не доказывает отсутствие всех кредитов.
- Разная концентрация доступных платёжных связей: меняются вопросы к снабжению/ликвидности; сам платёж не доказывает зависимость.
- Две роли в одной компании: меняется порядок, права остаются прежними.
- В restricted-аккаунте открыть прямую ссылку на чужую компанию/запуск: доступ не появляется из GROUP_ID/ракурса.
- Обновить страницу, вернуться Back/Forward, открыть мобильный размер и источник с клавиатуры: контекст сохраняется.

## 4. Если нужен живой проход

Используются только ключ и модели организаторов из [конфигурации](hackathon-configuration.md), `APP_MODE=live`. Допустим `gateway` без подтверждённого тарифа; перед вызовом проверяется общий лимит 500 ₽/сутки, ₽/ответ не вычисляется. Без Brave доступны RSS ЦБ и URL/текст. Не запускайте полный платный набор автоматически при демонстрации.

Пример реального источника из приёмки — пресс-релиз ЦБ от 23.10.2026, [smoke/usage](hackathon-live-smoke.json). UI покажет реальную доступность источника сегодня; исторический successful report не является обещанием доступности API на любой день.
