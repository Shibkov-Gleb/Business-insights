# Сценарий демонстрации жюри

1. Выполнить `pnpm hackathon:up`, дождаться migrate/import, открыть localhost:3010. На входе видны маркировки demo и моделируемой интеграции.
2. «Открыть демонстрацию» → постоянный блок «Новостная аналитика». Раздел также доступен в навигации.
3. Выбрать «Северный металл · синтетический», CFO/казначея, нажать «Исследовать». Показать реальные стадии SSE и trace. Платных вызовов в demo нет.
4. Открыть событие ставки. Разобрать признак кредита, последствия, проверку договора и основания. Если актуальная проверенная банковская цитата не найдена, это показано явно. Для примера с банковским тезисом открыть сигнал валютных расчётов/поставок с пометкой «Есть банковский тезис с цитатой»; проверить дату/страницу и оригинал PDF. Confidence OCR и неподтверждённые числа показаны отдельно.
5. Выбрать «АгроКонтур · синтетический» без признака кредита, исследовать тот же набор. Сравнить значимость и объяснение. Для прежней компании выбрать бухгалтера: порядок меняется без семи генераций.
6. В контексте открыть платёжную концентрацию и источник признака. Для исходной компании показать место/долю выручки внутри набора, неизвестные единицы. Не называть это долей рынка. Группы содержат только разрешённые компании.
7. В банковском корпусе открыть обзор стали 2021 года. Показать неизвестный день публикации золота и отсутствие Commodities performance.
8. Из материала перейти в приватный чат, задать новый вопрос. Показать ракурс, основания и приватность. Отправить материал на экспертный разбор, добавить экспертную заметку.
9. Добавить непоказанную новость по URL/тексту. Она проходит тот же граф; инструкции внутри источника не меняют инструменты/права. Live — только с разрешённым ключом и известной ценой.
10. В настройках показать 500 ₽/сутки, потрачено/резерв, отсутствие organiser gateway и блокировку платных вызовов. Открыть отчёты качества и матрицу соответствия.

Сведения дополнены тремя явно синтетическими бизнесами >15 млрд ₽; это не названия реальных клиентов. Оригиналы CSV/PDF вне Git. Для внешнего развёртывания заменить демонстрационные пароли и настроить TLS.

Финальный живой прогон: Gemma extraction, GLM interpretation/review/chat, подтверждение usage и дневного лимита, отложенные 20 сочетаний и новые новости, экспертная банковская атрибуция. До этого `alfa-hackathon-v1` не создаётся.
