# Руководство пользователя

[Документация](README.md) · [Быстрый сценарий жюри](hackathon-judge.md)

## Основной путь

1. Войдите в локальный аккаунт. В demo доступна кнопка демонстрации; в live — форма email/пароль. Авторизация банка моделируется.
2. На главной откройте **«Новостная аналитика»**. Точка входа продублирована в постоянной навигации.
3. Выберите разрешённую компанию или группу. Группа не открывает чужие компании: расчёт строится только по доступным участникам.
4. Укажите профессиональный ракурс и интересы. Отфильтруйте период, отрасль и категорию риска. Ракурс не предоставляет дополнительных прав.
5. Нажмите **«Исследовать»**. Видны настоящие стадии процесса, а не вымышленный процент. В live действие может расходовать общий бюджет команды.
6. Откройте материал, проверьте основания и, при необходимости, задайте уточняющий вопрос.

## Как читать материал

| Раздел                  | Что означает                                                                      |
| ----------------------- | --------------------------------------------------------------------------------- |
| Что произошло           | Внешнее событие; цитата и дата не равны выводу модели                             |
| Почему это важно вам    | Связь с доступными признаками компании и платёжными зависимостями                 |
| Как оценивает банк      | Точная датированная цитата из PDF либо сообщение об отсутствии подходящей позиции |
| Возможные последствия   | Риски и возможности как сценарии, а не свершившиеся факты                         |
| Что проверить           | Вопросы к договорам, данным компании или источникам                               |
| Основания и ограничения | Новости, CSV-поле/строка, расчёты, банковская страница, неизвестные данные        |

Источник открывается в боковой панели; банк допускает просмотр исходного PDF. Проверяйте дату: документ 2021 года не описывает текущую позицию. `ocr_uncertain` означает, что распознавание не даёт подтверждённого числового факта. Отсутствие банковской позиции не заполняется ответом от имени банка.

## Ракурсы и права

| Ракурс               | Основной акцент ранжирования                |
| -------------------- | ------------------------------------------- |
| Собственник          | Стратегия, спрос, финансирование            |
| Генеральный директор | Стратегия, снабжение, спрос                 |
| Финансовый директор  | Финансирование, ликвидность, валютные риски |
| Главный бухгалтер    | Регулирование                               |
| Казначей             | Ликвидность, валютные риски, финансирование |
| Другой C-level       | Стратегия, снабжение                        |
| Сотрудник            | Спрос, снабжение                            |

Порядок меняется на основе единой оценки компании: семь отдельных ответов заранее не покупаются. Право чтения/редактирования задаётся `CompanyGrant` и membership. Наличие общего `GROUP_ID` или связанного физлица не является разрешением.

## Контекст компании

Доступны подтверждённые признаки, происхождение, платёжные связи и позиция внутри предоставленного набора. Выручка CSV может иметь неизвестные единицы; доля внутри датасета не является долей рынка. Связь через физлицо не доказывает владение, платёжная концентрация не доказывает операционную зависимость.

Уточнение профиля требует явного подтверждения. Ручное значение хранится отдельно от CSV, создаёт новую версию. Если кто-то изменил контекст раньше, сервер вернёт конфликт версии: перечитайте данные и подтвердите новое решение.

## Новая новость, чат и обратная связь

- **«Добавить новость»**: введите заголовок и URL либо текст с происхождением. Недоступную страницу можно заменить вручную добавленным текстом. Она обрабатывается тем же графом; инструкции внутри источника не управляют инструментами.
- **«Обсудить с помощником»**: приватный чат с текущим ракурсом и разрешёнными основаниями. Старые demo-ответы не используются как примеры для живой модели. Переписка не публикуется команде автоматически.
- **«Полезно» / «На экспертный разбор»**: отметьте нерелевантный материал, неверное основание или банковскую атрибуцию. Экспертный экран сохраняет статус и заметку разбора.
- **«Исследования»**: стадии, источники, существенные промежуточные результаты, версии, ошибки и бюджет. Скрытые рассуждения модели не сохраняются.

## Состояния и восстановление

| Состояние                   | Действие пользователя                                                                   |
| --------------------------- | --------------------------------------------------------------------------------------- |
| Выполняется                 | Можно наблюдать стадии; при необходимости отменить                                      |
| Есть пробелы / `partial`    | Прочитать ограничения и непроверенные события; не считать их подтверждёнными            |
| Отменено                    | Уже опубликованные предыдущие результаты сохраняются                                    |
| Ошибка источника            | Проверить URL или добавить текст; не трактовать недоступность как исчезновение компании |
| Ошибка доступа/модели/квоты | Проверить настройки; постоянная ошибка не запускает бесконечные повторы                 |
| Неизвестная стоимость       | Это не ноль: тариф не подтверждён, показан общий счётчик шлюза                          |
| Обрыв SSE                   | Клиент переходит на polling и прекращает его после завершения задачи                    |

Ссылки, компания, ракурс и фильтры сохраняются в URL. Доступны Back/Forward, клавиатура и `prefers-reduced-motion`; мобильная версия не требует горизонтальной прокрутки основной страницы.
