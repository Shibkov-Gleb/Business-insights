## Однозначный идентификатор на дедлайн

Техническая live-приёмка зафиксирована кодом `3ee6c33ea940a70835aa8fab5f89cb2a0753eb57`. Документация может быть обновлена позже: **для фактической сдачи обязательно зафиксировать HEAD выбранного кандидата и время**, не подменяя его этим историческим SHA.

```sh
git branch --show-current
git status --short
git rev-parse HEAD
git show -s --format=fuller HEAD
```

Передайте жюри ссылку `https://github.com/Shibkov-Gleb/Business-insights/tree/COMMIT_SHA` с фактическим значением. Изменения после дедлайна не включаются в заявленную сдачу. Для публичного репозитория просмотр доступен без приглашения; если видимость изменится на private, предоставьте доступ `alfa-hack-2026`.

## Статус финального выпуска

- [x] Собственная реализация и интерактивный прототип, demo без ключей.
- [x] Полный доступный CSV/PDF-корпус, локальный OCR, источник/дата/quality gaps.
- [x] Gemma/GLM, реальная новость и чат, общий лимит шлюза без выдуманных тарифов.
- [x] Typecheck/lint/unit/integration/E2E/build и сохранность по опубликованному протоколу.
- [x] Авторская live-регрессия: P@5=0,80, механические references=100%, формальные нарушения bank refs=0.
- [ ] Независимая смысловая экспертиза банковской атрибуции/рекомендаций и новый не просмотренный набор.
- [ ] Финальное заключение, зафиксированный дедлайн-SHA и аннотированный `alfa-hackathon-v1`.

Тег не создаётся только ради оформления репозитория. Создание финального тега после закрытия условий не должно изменять `personal-v1`/`personal-v1.1` или сливать ветку в main. Внешний сервер — рекомендация, не причина скрывать локальные результаты или обещать несуществующее размещение.

## Открытые ограничения

Неизвестны реальные market shares и единицы части CSV, отсутствует Commodities performance, часть OCR-чисел не сверена вручную. Полнота поиска и семантический дедуп не доказаны. Тарифы неизвестны: цена в ₽/ответ `null`, gateway-контроль лимита работает по утверждённой политике. [Матрица](hackathon-compliance.md) не объявляет эти пробелы закрытыми.
