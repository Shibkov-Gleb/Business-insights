## Границы

Проверки от 24–25.10.2026 описывают зафиксированную версию кода и окружение приёмки. Доступность чужого API или локального сервера сегодня из этих отчётов не следует. Обновление документации 26.10 не запускает платные исследования и не заменяет независимую смысловую экспертизу.
